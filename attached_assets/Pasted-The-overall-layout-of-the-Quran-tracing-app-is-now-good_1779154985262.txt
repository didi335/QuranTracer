The overall layout of the Quran tracing app is now good. The Quran size, spacing, and page layout are mostly working well. DO NOT redesign the entire app layout.

The MAIN issue now is the tracing system itself.

Right now tracing is broken because:
- It only traces vertically properly
- Horizontal movement creates broken or tiny disconnected lines
- Arabic letters require smooth curved and horizontal strokes
- Scrolling and tracing are conflicting
- The tracing experience is not smooth or user-friendly

This needs a full tracing interaction redesign while keeping the current layout clean and simple.

========================
1. REDESIGN TRACING INTERACTION
========================

The app needs a dedicated tracing mode system.

Current issue:
- The app cannot properly distinguish between:
   - scrolling
   - tracing

This causes broken strokes and accidental scrolling.

Fix:
Create a clear “Draw Mode” toggle.

Behavior:
- Draw Mode OFF:
   - Finger = scroll only
   - User can navigate pages normally

- Draw Mode ON:
   - Finger = trace only
   - Scrolling disabled while drawing

IMPORTANT:
- Apple Pencil should ALWAYS draw regardless of Draw Mode.

========================
2. FIX HORIZONTAL + CURVED STROKES
========================

Current issue:
- Tracing only responds properly to vertical movement
- Horizontal Arabic strokes become dotted or disconnected
- Curves are jagged

Arabic letters require:
- Horizontal movement
- Curved movement
- Diagonal movement
- Continuous flowing strokes

Fix the drawing engine completely.

Requirements:
- Continuous line rendering in ALL directions
- Proper interpolation between points
- Bézier curve smoothing
- High-frequency input sampling
- No broken segments

The tracing should feel:
- Smooth
- Fluid
- Natural
- Like real handwriting
